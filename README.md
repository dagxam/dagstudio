# DAGSTUDIO

Репозиторий для исходников сайта https://dagstudio.ru/.

Первичный импорт публичной версии сайта выполняется автоматически через GitHub Actions. Серверные PHP-файлы, конфигурация и база данных не могут быть получены из публичного HTTP-ответа и должны переноситься отдельно с хостинга, если сайт использует серверную часть.
