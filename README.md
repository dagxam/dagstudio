# DAG STUDIO

Официальный сайт DAG STUDIO.

## Готово в первой версии
- Главная страница по утверждённому тёмному референсу.
- Фирменная терракотово-чёрная айдентика.
- Векторизованные версии горизонтального логотипа и квадратного знака.
- Адаптив для ПК, планшетов и телефонов.
- Блок услуг 4×2 на широком экране.
- Форма заявки с отправкой через PHP на `admin@dagstudio.ru`.
- Карта Яндекс.
- Базовые защитные HTTP-заголовки через `.htaccess`.
- `robots.txt`, sitemap и web app manifest.

## Структура
- `index.html` — главная страница.
- `assets/css/style.css` — визуальная система и адаптив.
- `assets/js/main.js` — меню, анимации и сообщения формы.
- `assets/img/` — векторные фирменные логотипы.
- `send.php` — обработчик формы заявки.

## Деплой
Сайт рассчитан на Apache/PHP-хостинг. Следующий этап — подключить FTP-деплой из GitHub после указания параметров FTP и каталога сайта на сервере.
